# NARA source confirmation

The selected series is *Records About the Ground Combat Operations by the Army During the Vietnam War, 5/20/1966–3/12/1973*, also called Situation Report Army (SITRA), National Archives Identifier 604416, in Record Group 218.

NARA's [Vietnam electronic records reference](https://www.archives.gov/research/military/vietnam-war/electronic-data-files) lists four ASCII translated data files, NIPS versions, and 49 pages of technical documentation plus two electronic documentation files. The [Catalog series description](https://catalog.archives.gov/id/604416) reports five file units and 2,281,045 logical data records across its holdings.

The Catalog description identifies four dates: Message Sent, Date of Last Update, Initiation Date, and Termination Date. Message Sent and Date of Last Update are present on all records; Initiation and Termination may be absent. NARA notes date inconsistencies in some records. The description also identifies UTM coordinates; operation type and name; armed-forces nationalities; location/province; unit identities and sizes; mission objectives; casualties and property losses; and supporting air and naval missions. Some operations or weekly summaries have multiple records that repeat the first five fields (Message Sent date, data type, paragraph number, military region, and part), which may provide source evidence for related records.

The four ASCII translations in the SITRA file units are `SITRA.TR.6668.txt` (1966–1968), `SITRA.TR.69.txt` (1969), `SITRA.TR.70.txt` (1970), and `SITRA.TR.7173.txt` (1971–1973). NARA's [translation layout](https://catalog.archives.gov/medialz/electronic-records/rg-218/SITRA/SITRA.TR.LAY.txt) defines 298 fixed columns: five control values in columns 1–12, fixed fields in columns 13–78, and seven periodic sets through column 298. The [technical documentation package](https://catalog.archives.gov/medialz/electronic-records/rg-218/SITRA/131.1DP.pdf) confirms Message Date, initiation, and termination dates use `YYMMDD`; last-update dates use five-character `YYJJJ`; and UTM values have a two-letter 100 km grid square plus six digits. It defines data types `S`, `L`, `E`, and `W` as small actions, large operations, enemy-initiated incidents, and statistical summaries; these map to the corresponding ontology report subtype labels. The source UTM omits the GZD; the importer tries `48Q`, `49Q`, `48P`, and `49P`, converts each candidate MGRS value, and accepts a unique point within that GZD's Vietnam bounds. Source files are available through the [Catalog series](https://catalog.archives.gov/id/604416).

The importer also decodes documented code tables for force/service nationality, country, operation/action type, province, objective, objective description, unit size and activity, military region, and casualty/loss category and type. Code labels are added beside the original source fields and to indexed report search text; graph lookup nodes retain the code as their key and use the documented label as their description. Undocumented or unrecognized values stay available as raw codes without an inferred label. The implementation is in `backend/app/code_values.py`.
